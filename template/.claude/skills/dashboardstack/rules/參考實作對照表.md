# 參考實作對照表

## Rule 1：依需求讀兩邊

**Why**：參考實作示範了整套怎麼接，clade rule 記的是 fleet 踩過的坑與與參考實作不同的決定；只讀一邊不是漏掉接法就是照抄到 fleet 不採用的做法。

**MUST**

- 依需求找到下表那一列，左欄的檔（路徑以 `YuDefine/nuxt-dashboard-layer` 根目錄為準）與右欄的 clade rule 都讀完再動手。
- 右欄的 clade rule 在 consumer 端投影在 `.claude/skills/clade-*/rules/` 底下，用 rule 檔名找。

| 需求 | 參考實作 | clade rule |
| --- | --- | --- |
| 宣告一個資源（欄位、標籤、表單／表格／匯入可見性） | `app/resources/users/users.resource.ts`、`app/utils/dashboard/resource/`、`modules/ds-resources.ts`、`app/plugins/runtime-resources.ts` | `data-table`、`nuxt-form-validation` |
| 通用 CRUD API（列表、單筆、新增、更新、刪除、聚合） | `server/api/[resource]/`、`server/utils/resources.ts`、`server/utils/filters.ts`、`server/utils/validation.ts` | `api-patterns`、`server-api` skill 的 `列表查詢契約判準` |
| 伺服器端分頁表格（分頁、排序、搜尋、篩選、欄位切換、多選） | `app/components/dashboard/table/`、`app/composables/dashboard/useServerTable.ts`、`useTableState.ts`、`useFilterDraft.ts`、`useColumnToggle.ts`、`useSelectionColumn.ts` | `data-table`、`nuxt-data-perf` |
| CSV 匯入匯出 | `app/components/dashboard/resource/import/`、`app/composables/dashboard/resource/useImport.ts`、`server/api/[resource]/import.post.ts`、`app/utils/dashboard/table/export-csv.ts` | `data-table` |
| 新增／編輯表單、檔案欄位 | `app/components/dashboard/resource/form/`、`useCreate.ts`、`useEdit.ts`、`server/utils/resource-multipart.ts` | `nuxt-form-validation`（日期欄位另見 `vendor/snippets/nuxt-calendar-field/`；multipart 見 `vendor/snippets/multipart-zod-body/`） |
| 多種檢視（表格、格狀、看板、行事曆、時間軸、動態） | `app/components/dashboard/resource/views/` | `data-table`、`ux-completeness` |
| dashboard 外殼（側欄、導覽、全站日期區間、sheet、全站搜尋） | `app/layouts/dashboard.vue`、`app/components/dashboard/`（`Navbar`、`SideNav`、`sheets/`）、`useDashboardDateRange.ts`、`useSheets.ts`、`useGlobalSearch.ts` | `dashboard-shell`、`nuxt-ui-conventions` |
| 組織、成員、角色、權限 | `app/components/dashboard/organizations/`、`server/api/admin/`、`server/utils/permissions.ts`、`require-permission.ts`、`require-role.ts`、`requireResourceAuth.ts` | `auth-roles`、`auth-data-path-consistency`、`user-lifecycle` |
| 使用者帳號（建立、停用、刪除、個人設定） | `server/api/users/`、`server/api/profile/`、`app/pages/dashboard/users.vue`、`app/pages/settings.vue` | `user-lifecycle`、`auth-roles` |
| 資料異動事件與稽核紀錄 | `server/events/`（先讀 `README.md`）、`app/pages/admin/events.vue` | `api-patterns` |
| 主題切換 | `themes/`、`app/plugins/theme-engine.ts`、`useTheme.ts` | `nuxt-ui-conventions` |

**NEVER**

- **NEVER** 讀或照搬參考實作的 `AGENTS.md`、`.agents/`、`.cursor/`：那是 DashboardStack 給它自家 agent 的指引，與 clade 投影衝突。
