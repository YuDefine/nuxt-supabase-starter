# 付費內容取得路徑

> 讀取時機：`nuxt-charts` SKILL.md Phase 2 step 1 要查付費資產時（Rule 1 的 clone 與新鮮度判定），以及 Phase 4 step 1 已過 Phase 3 授權前置、要把 block 或 template 原始碼落進 repo 時。

付費 block 與 template 平常一律從 PRIVATE 鏡像 `YuDefine/nuxt-charts-assets` 取。鏡像由 clade 的 `vendor/scripts/nuxt-charts-assets-sync.ts` 維護（desk 每週同步官網 Code 與 `nuxtcharts/*` 上游 repo）；官網、CLI、上游 repo 都是它的來源，不是本 skill 的取得步驟。

# Rule 1 - 先 clone 鏡像判新鮮度，FRESH 就從鏡像取 block；STALE 或缺 block 才退回官網 Code

- Level: `MUST`
- clone 與判定：在 session scratchpad 底下跑下面這段（clone 目錄 MUST 在任何 git repo 之外；每次用 `mktemp -d` 開新目錄重新 clone，不沿用、也不刪舊目錄）。它先驗鏡像是 `PRIVATE`（`付費授權與token保管.md` Rule 1）才 clone，再印 `FRESH <鏡像短 sha>` 或 `STALE <原因>`；印 `NOT-PRIVATE <可見度>` 或 `CLONE-FAILED`（404、未登入 gh）就停下回報，**NEVER** 改去別處找副本：

```bash
v=$(gh repo view YuDefine/nuxt-charts-assets --json visibility -q .visibility 2>/dev/null)
[ "$v" = PRIVATE ] || { echo "NOT-PRIVATE ${v:-查不到}"; exit 1; }
D="$(mktemp -d "<session scratchpad>/nca.XXXXXX")/nuxt-charts-assets"
gh repo clone YuDefine/nuxt-charts-assets "$D" -- --quiet || { echo "CLONE-FAILED"; exit 1; }
ok=$(git -C "$D" for-each-ref --format='%(taggerdate:unix)' refs/tags/sync/last-ok)
if [ -z "$ok" ]; then echo "STALE never-synced"
elif [ $(( $(date +%s) - ok )) -gt $(( 14 * 86400 )) ]; then echo "STALE last-ok>14d"
else echo "FRESH $(git -C "$D" rev-parse --short HEAD)"; fi
```

- `FRESH`：選 block 只讀 `manifest.json` 與 `<類別>/<標題 slug>.png`（manifest 的 `png` 是 `null` 表示官網沒有 Example 可截，改開該筆 `source_url` 看官網的 Example）；落地時把 `<類別>/<標題 slug>.vue` 複製成 consumer 的元件檔，SFC 呼叫 `useResponsiveHeight` 的話一併複製鏡像的 `composables/useResponsiveHeight.ts`。來源註記帶 `FRESH` 印出的鏡像短 sha（`付費資產優先與來源註記.md` Rule 2）。
- `STALE`，或 `manifest.json` 沒有要的 block：才退回官網 Code，並在 PR 說明寫出「鏡像 STALE（原因）」或「鏡像缺 `<類別>/<標題>`」。退回步驟：
  1. 用持有授權的 GitHub 帳號（Charles5277）登入的 desk 桌面 Chrome profile：`agent-browser --headed --session <名稱> --profile Main`，同一 session 每個指令都帶同一組旗標（少帶會被重開成暫存 profile，等於未登入）；不在 desk 上時經 `ssh desk bash -l -s` 跑。頁面顯示「Please log in to get access to the source code of premium components.」就照 `agent-browser` skill 請 Charles 在 desk KasmVNC 的桌面 Chrome（Main）登入。
  2. 開 `/blocks/<類別>`，在目標 block 標題旁按「Code」，取 `<pre>` 的完整 SFC。block 內的「View Details」是示範 UI 的按鈕，不是取用入口。
  3. 這條路取得的 block，來源註記不帶 `@<sha>`。
- 要的 block 列在 `manifest.json` 的 `absent_blocks`（官網類別頁有標題、Code 分頁卻沒有原始碼）：官網那頭同樣拿不到，**NEVER** 退回官網重抓或照 Example 截圖重寫，改選同類別其他 block，或停下回報缺哪一個。
- 不論從哪取得：SFC 存進 consumer 後照 `圖表配色與無障礙判準.md` 換掉寫死的色碼；SFC 裡有 `Lib` 前綴元件（例：`<LibProgressCircle>`，註解寫「from CLI」）時，CLI catalog 沒有這類元件，**停下回報**哪個 block 缺哪個元件，或改用 npm chart／自組元件替代並在 PR 說明，**NEVER** 照 docs 範例憑印象重寫一個同名元件。
- `sync/last-failure` 不影響判定：同步失敗時鏡像內容不會被動到，仍是上次成功那一版，修復由 clade 稽核追。
- 理由：鏡像把「登入、逐個按 Code、選 repo」收成一次同步，平常取用只剩 clone；但鏡像停更時讀到的會是舊版，所以先判新鮮度。

# Rule 2 - template 從鏡像的 `templates/<name>/` 取

- Level: `MUST`
- 照 Rule 1 clone 鏡像後，template 清單看 `manifest.json` 的 `templates`（`name`、上游 `repo`、`commit`）；只把要用的檔從 `templates/<name>/` 複製進 consumer。**NEVER** 在 consumer 裡 clone、加 submodule 或整包 vendor 進來。
- 要的 template 在 `manifest.json` 的 `absent_templates`（CLI 與上游 repo 都拿不到）就停下回報，**NEVER** 從別處找來路不明的副本。
- 鏡像 `STALE` 時 template 仍可用（上游 template 很少變），但在 PR 說明寫出鏡像 STALE 與它記錄的 `commit`。
- `YuDefine/template-*` fork 已由鏡像取代，**NEVER** 再從 fork 取用，也 **NEVER** 往 fork commit。
- 理由：template 散在多個受邀 repo、讀取權限因人而異；鏡像收成一處並記下上游 commit。

# Rule 3 - 驗證取得能力時不下載任何原始碼

- Level: `MUST`
- 確認鏡像可讀：`gh api repos/YuDefine/nuxt-charts-assets --jq '[.visibility,.permissions.pull]|@tsv'`，回 `private	true` 才算可讀，404 就是沒有權限（向 YuDefine org 管理者要讀取權）。
- 確認鏡像新鮮：看 tag 不必 clone——`gh api repos/YuDefine/nuxt-charts-assets/git/ref/tags/sync/last-ok --jq .object.sha` 取 tag 物件，再 `gh api repos/YuDefine/nuxt-charts-assets/git/tags/<sha> --jq .tagger.date`；判準同 Rule 1（last-ok 超過 14 天才算 STALE）。
- 確認官網 block 可取（只在要走 Rule 1 退回步驟時）：登入狀態下開任一 `/blocks/<類別>`，按「Code」看得到 SFC，而且沒有「Please log in」字樣。
- 理由：驗證只為了確認通路，下載原始碼就落入 `付費授權與token保管.md` Rule 1 的管轄。
