
# Rule 1 - `/track` MUST 標在真正做事的 session 上，NEVER 只標到轉手派工的主持者

- Level: `MUST`
- 一般工作 session（自己做這件事）：標自己——`mark --title … --session '${CLAUDE_SESSION_ID}'`；`CLADE_WORK_ID`、`HERDR_PANE_ID` 與 `CLADE_DISPATCH_ID` 由 script 自動帶入，有 work id 就追整件工作。已開著的 session 中途補標也是同一條指令。
- 要追的是一份 plan：`--work <plan 的 work_id>`，在哪個 session 下都可以。
- Charles 明說只要這一個 session（不管後續接手者）：加 `--session-only`。
- 主持者 session（`/coordinator` 主持中）收到 `/track`、而這件工作會派給 worker：加 `--follow-next-dispatch`，watch 會把本主持者在標記之後派出的**第一個** dispatch 綁上，並改追那個 dispatch 的整件工作；還沒綁上前看板顯示「等主持者派出」。主持者自己的 `CLADE_WORK_ID` 是主持卡，**NEVER** 不加 `--follow-next-dispatch` 就在主持者 session 裡標（會追到主持卡）。
- 已經派出去的 worker：`--dispatch <dispatch_id>`，script 從 record 取它的 work id。
- Charles 在 Remote Control session（跑在 desk）裡送 `/track`：同樣標自己（`--session`），watch 以 session id 點名。
- cloud session：追蹤名單只在 desk 的 `~/.cache/clade/coordinator/`，cloud 機器碰不到；cloud 派工也不寫 Herdr dispatch record，`--follow-next-dispatch` 綁不到它。cloud 的件 MUST 由主持者 session 以 `--session <cloud session id>` 標記。
- 本機沒有 `~/offline/clade/vendor/scripts/tracked-session.ts`（cloud session、別台機器）：**NEVER** 回報已標記；直接告訴 Charles 這個 session 標不起來，請在主持者 session 送 `/track` 並附本 session id。

## Good Example

- 這個例子是好的，因為主持者知道工作會派出去，標的是下一個派工而不是自己。

```bash
node ~/offline/clade/vendor/scripts/tracked-session.ts mark --title '調整 version-upgrade 的 drift 判準' --session "$SID" --follow-next-dispatch
```

## Bad Example

- 這個例子是壞的，因為主持者把自己標起來就去派工，worker 被收割時不會有通知。

```bash
node ~/offline/clade/vendor/scripts/tracked-session.ts mark --title '調整 version-upgrade 的 drift 判準' --session "$SID"
```

# Rule 2 - 派出 worker 之後 MUST 確認追蹤列已綁上 dispatch

- Level: `MUST`
- `--follow-next-dispatch` 只綁「標記之後的第一個」dispatch。主持者同時派了別件、或先派了別件才派這件時，綁上的可能是錯的那件。
- 派出後跑 `tracked-session.ts list --all`：該列應顯示 dispatch 已綁；綁錯或還在「等派出」→ 以 `mark --title … --dispatch <正確 id>` 補登記，再 `unmark <錯的追蹤 id>`。

# Rule 3 - 追蹤 NEVER 當成保留；要 session 不被收用 keep／hold

- Level: `NEVER`
- 追蹤只保證「收掉時一定通知並留接續檔」。要它不被收：keep-panes 名單或 `pane-hold.ts`，那是主持者的判準，不是本 skill。
- **NEVER** 為了「怕被收」同時 keep 又 track 同一件而不寫理由——keep 會到期，到期後仍由追蹤兜底通知。
