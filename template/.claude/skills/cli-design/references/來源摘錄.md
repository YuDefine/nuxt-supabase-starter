### 為什麼重做

- Wrangler「only provides commands for around 280 operations, and Cloudflare offers thousands」。
- 命名各自為政：「inconsistent terminology across `d1 info`, `hyperdrive get`, `workflows describe`」。
- 2026-04 的文章把 agent 視為 CLI 的主要使用者。

### 命令面從哪裡來（H1–H3）

- 2026-04：一份新的 TypeScript schema，「can define the full scope of APIs, CLI commands and arguments, and context needed to generate any interface」，本身「'just' a set of TypeScript types with conventions, linting, and guardrails」。
- 2026-09：命令「directly from the API schema that powers our API documentation and SDK generation」；「if we annotate this with just a little more information, we can use it as the source for Forge to make a CLI」。
- 兩篇文章對來源層的描述不同（TypeScript schema 與 OpenAPI 加註解），無法確認是否為同一層。
- Forge「runs in CI … It lints every change, and then generates preview builds」。`cf dev`、`cf build` 是手寫命令，疊在生成的命令之上。
- 文件：「More than 2,900 commands, most of them generated from the schemas that describe the Cloudflare API」。

### 命名（A1–A3）

- 「It's always `get`, never `info`.」
- 「Always `--force`, never `--skip-confirmations`.」（文章沒有提到 `--yes`）
- 「Always `--json`, never `--format`, and always supported across commands.」
- 規則「enforced at the schema layer」。
- 命令順序 `cf <產品> <動詞>`：歸納。

### 輸出（B1–B7）

- 「Results go to standard output as JSON … it contains only the result, so an agent can parse it or filter it with `jq`.」
- 上線文：「JSON is the default interface, pretty printed for humans and condensed for agents」。
- 文件：「JSON output is indented, whether or not standard output is a terminal.」兩者互相矛盾，B7 因此不跟其中一邊。
- Local Explorer：「a mirror of the Cloudflare API that only modifies local data」；輸出要「clearly signal whether commands are applied to remote or local resources」。
- 分頁、色碼：沒有公開說明。

### 錯誤與非互動（C1、C5、C6、D1–D3）

- 「A failed command exits with a non-zero status and prints the error to standard error.」
- 「If an agent types a command that does not exist, `cf` lists the closest matches.」
- 非互動判定：「no terminal, or when it detects a CI environment, for example through the `CI` environment variable」。
- 「Prompts use their default answer. Prompts without a default fail, so pass the value as an option instead.」
- **反例**：非互動模式下沒帶 `--force` 的刪除，會在 stderr 印 `Aborted.`、不做任何變更並 exit 0。文件自己警告「A successful exit does not mean the resource was deleted.」C6 因此偏離 cf。
- 完整退出碼表：沒有公開說明。

### 破壞性操作（E1–E2）

- 「Add `--dry-run` to print the request as JSON without sending it.」「Dry runs need no credentials.」
- 冪等：沒有公開說明。

### 可發現性（F3、F4、F6）

- 「`cf cli search "<whole task>"` runs locally and needs no credentials」，「returns up to five matches as a JSON array, best match first」。
- 「Root and group `--help` output starts with a reminder for agents to use `cf cli search` first.」
- AGENTS.md 建議句：「When interacting with Cloudflare, use the `cf` CLI unless the project has a Wrangler configuration file.」

### 認證與設定（G1–G4、G6、G7）

- `CLOUDFLARE_API_TOKEN`「Takes priority over any stored login」；`CLOUDFLARE_ACCOUNT_ID`、`CLOUDFLARE_ZONE_ID` 用來選帳號與 zone。
- 「More than one account available but unable to select one in non-interactive mode.」
- CI 下帳號名稱顯示為「(redacted)」；telemetry 可用 `CF_SEND_TELEMETRY=false` 或 `DO_NOT_TRACK=1` 關閉。
- `cloudflare.config.ts` 提供型別資訊給 agent 與 LSP 工具。
