# Rule 1 - 四條全過才算完成，未過的先查 cookbook Gotchas

- Level: `MUST`
- 驗收清單，四條都要實測通過：
  - [ ] `curl -I https://<hostname>` 回 200／301
  - [ ] 桌面瀏覽器開 `https://<hostname>` 看到 dev server 頁面
  - [ ] 手機或另一台裝置開 `https://<hostname>` 跑完 OAuth flow，登入成功
  - [ ] 登入後 reload 頁面，session 還在（驗 cookie `Secure` 在 HTTPS 下正常）
- 任一條沒過，MUST 先依症狀對 cookbook § Gotchas 表找解法再修；NEVER 只過 `curl` 就宣告完成。

## Good Example

- 這個例子是好的，因為登入成功後仍做 reload 驗收，抓到 session 丟失並對 Gotchas 修正。

```text
curl 200、桌面可開、手機登入成功 → reload 後回到登入頁
→ cookbook § Gotchas「Cookie 沒 Secure」→ session cookie 設 Secure=true、SameSite=Lax → 重跑四條全過
```

## Bad Example

- 這個例子是不好的，因為只看到登入成功就結束，沒驗 reload 後 session 是否保留。

```text
curl 200、手機登入成功 → 回報「tunnel 完成」
```
