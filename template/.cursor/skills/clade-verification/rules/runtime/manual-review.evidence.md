# Cursor evidence transport

Cursor's Task/Agent catalog can carry bounded mechanical evidence work only when the current catalog exposes it and the result includes a completion receipt. The shared `#N` / `#N.M`, kind, marker, freshness, and annotation contracts remain authoritative. Cursor's IDE browser is the native surface for browser evidence when exposed; it does not grant a native writer for user-owned review decisions.
