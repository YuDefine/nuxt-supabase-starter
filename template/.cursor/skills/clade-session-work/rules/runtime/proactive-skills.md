# Cursor native orchestration and browser carrier

Use Cursor's native `Task` surface for bounded delegation only when its current model catalog and task events are exposed. Keep model qualification and completion correlation from the common rule. A missing Task surface is blocked; it does not authorize a cross-runtime emulation.

For browser verification, use the Cursor IDE browser through `cursor-ide-browser` and its `browser_tabs`, `browser_navigate`, `browser_lock`, snapshot, interaction, and unlock operations. External browser carriers are not substitutes for this native path when an IDE browser is required.
