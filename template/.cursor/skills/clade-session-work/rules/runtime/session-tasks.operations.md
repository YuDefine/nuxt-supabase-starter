# Cursor close-out and handoff carrier

Cursor close-out may use native `Task` events and `cursor-ide-browser` only for their observed operations. Canonical Herdr transport remains portable CLI work; an idle/done Task pane is not a correlated completion outcome. If the native surface cannot perform a required action, keep the action blocked.
