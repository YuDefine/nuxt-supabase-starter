# Cursor design checkpoint transport

Cursor has no verified native `/impeccable` Skill in this adapter. A checkpoint requires an authorized Cursor Task/Agent entry that can run the impeccable CLI (`impeccable detect`, `critique-storage`) plus the Cursor IDE browser for any browser inspection, with the critique snapshot, audit, and detector receipts captured. If either capability is absent, keep the checkpoint blocked under the shared gate rather than claiming a text-only review.
