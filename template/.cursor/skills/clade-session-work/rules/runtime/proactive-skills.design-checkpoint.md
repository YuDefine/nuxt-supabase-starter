# Cursor design checkpoint transport

Cursor has no verified native `/design` or `/impeccable` Skill in this adapter. A checkpoint requires an authorized Cursor Task/Agent entry plus the Cursor IDE browser for any browser inspection, with fidelity and audit receipts captured. If either catalog capability is absent, keep the checkpoint blocked under the shared gate rather than claiming a text-only review.
