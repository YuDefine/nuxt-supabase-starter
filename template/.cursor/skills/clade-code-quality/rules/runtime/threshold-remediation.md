# Cursor threshold review transport

When the shared threshold rule requires a Fable structural review, use the approved review transport for the current Cursor session and record the actual runtime and model separately. A Cursor Task model is not a Fable review unless the current routing contract explicitly says so. The brief MUST include the threshold, measured history, current remediation and measured reduction; the reviewer only returns advice and reasons and NEVER edits files. If a verified Fable-capable transport is unavailable, keep the remediation gate incomplete and report that concrete gap.
