# Cursor threshold review transport

When the shared threshold rule requires the read-only Opus 5.5 structural review, use the Herdr create-only Claude carrier (`--launcher cc|ccw --model claude-opus-5-5 --effort medium`) and record the actual runtime and model separately. A Cursor Task model is not an Opus 5.5 review. The brief MUST include the threshold, measured history, current remediation and measured reduction; the reviewer only returns advice and reasons and NEVER edits files. If a verified Opus 5.5 carrier is unavailable, keep the remediation gate incomplete and report that concrete gap; do not substitute an unapproved or banned reviewer.
